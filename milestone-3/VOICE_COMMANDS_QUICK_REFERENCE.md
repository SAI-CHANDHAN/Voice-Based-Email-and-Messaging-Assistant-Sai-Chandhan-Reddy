# 🎤 Voice Commands Quick Reference

## 🚀 Quick Start
1. Wake Govind: **"Hey Govind"** or click mic button
2. Say your command clearly
3. Follow voice prompts for multi-step actions

---

## 📧 Gmail Commands

| Command | Action |
|---------|--------|
| "Open Gmail" | Navigate to Gmail |
| "Check my email" | Read inbox |
| "Read my emails" | List recent emails |
| "Summarize this email" | Get email summary |
| "Reply to this email" | Start reply flow |
| "Compose email" | Start new email |
| "Send email to [name]" | New email to contact |

| Command | Action |

## 💡 Pro Tips

### Natural Language Works!
Instead of rigid commands, speak naturally:
- ✅ "Hey Govind, do I have any new Telegram messages?"
- ✅ "Can you summarize my Telegram activity?"
- ✅ "I want to send a message on Telegram"

### Combining Platforms
- "Check my Gmail and Telegram"

### Context Awareness
When on a specific page (Gmail/Telegram):
- "Read this" → Reads current item
- "Reply" → Replies to current message
- "Send message" → Uses current platform

## ⚠️ Important Notes

- Always start with **"Hey Govind"** wake word
- Speak clearly and at normal pace
- Wait for Govind's response before next command
- Use **"Cancel"** to stop any operation
- Microphone must be enabled in browser

---

## 🔧 Troubleshooting

| Issue | Solution |
|-------|----------|
| Commands not recognized | Check mic permissions, speak after wake word |
| Platform not available | Ensure backend running, check connection |
| Action failed | Verify you're authenticated to the platform |
